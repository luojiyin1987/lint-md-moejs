# lint-md-moejs

Experimental Go host for evaluating whether the existing JavaScript [`@lint-md/core`](https://github.com/lint-md/lint-md) can execute inside [`moejs`](https://github.com/Calcium-Ion/moejs).

This is a research prototype, not a drop-in replacement for `@lint-md/cli`. The TypeScript implementation is the compatibility reference.

Experiments belong in separate, reviewable pull requests. No runtime, performance, or compatibility claims are made by the baseline repository.
